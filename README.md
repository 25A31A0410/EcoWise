# 🌱 EcoWise

EcoWise is a web application for discovering and comparing sustainable, reusable, refillable, and ingredient-conscious everyday products.

## Features

- Browse and search eco-friendly products
- Filter products by category
- View product details and ingredient information
- Explore packaging information and alternatives
- Compare products
- Save products to a wishlist
- Register and log in
- View a user profile
- Explore product recommendations and Eco Scores

## Technologies Used

- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Authentication:** JWT and bcryptjs
- **Database:** MongoDB Atlas integration in progress
- **Version Control:** Git and GitHub

## Running the Project

The frontend and backend are run separately on your local computer. Setup instructions will be added as development progresses.

## Project Status

EcoWise is under active development. Features and database integration are being improved step by step.
